A LangGraph ReAct agent (running Groq's Llama 3.3 70B) that dynamically routes each query across a calculator, code execution, a custom RAG pipeline, and live web search — rather than relying on one tool for everything.

LangGraph FAISS HuggingFace Tavily

This project started with a conversation with my friend Stanley Joel, who works at Cognizant. He introduced me to RAG and AI agents, then invited me to LangChain events where I heard people talk about ideas that felt new, practical, and full of possibility. The image here was taken at one of those events.

Before that, RAG was just something I had seen online. But after learning, I wanted to build something myself instead of only reading about it. This agentic RAG system became my way of learning how retrieval, agents, context, and memory can work together in a real project.

More than anything, this project made me want to keep going. It gave me a real interest in agent architectures, better retrieval systems, memory, and multi-agent workflows. One conversation opened the door, and building this project was my first step through it.
